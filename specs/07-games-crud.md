# 07 — Games create + list + detail (org-scoped)

- `lib/games/actions.ts`: `createGame({ prompt })` server action (`'use server'` file-level). `await auth()` requires `userId` + `orgId` (throws otherwise — forced-org model, no personal accounts). Validates non-empty prompt (max 2000), title = whitespace-collapsed prompt sliced to 80 chars (raw truncation until AI titles). Inserts `{ orgId, title }`, returns `{ id, title }` only, `revalidatePath("/")`.
- `lib/games/queries.ts`: `listGames()` (no `orgId` → `[]`) selects `{ id, title }` where `orgId`, `orderBy desc(createdAt)`; `getGameById(id)` adds `and(eq(id), eq(orgId))`, returns `null` when missing/foreign-org. Plain async fns (no `"use server"`, no cache layer yet).
- `components/chat-composer.tsx`: now `"use client"`; controlled textarea, `useTransition` + `useRouter`; form submit + Enter-to-send calls `createGame`, then `push(/game/[id])` + `refresh()` (refresh forces `(dashboard)` layout to refetch `listGames`). Inline `role="alert"` error. Suggestions set prompt text.
- `components/app-sidebar.tsx`: stays client, takes `games: GameListItem[]` prop; `GamesList` renders `SidebarMenu` links (`render={<Link/>}`, `isActive` via `usePathname`) in Recents + collapsed Games popover, `GamesEmpty` fallback. New-game button links `/`.
- `app/(dashboard)/layout.tsx`: async server layout, `await listGames()`, passes to `AppSidebar`.
- `app/(dashboard)/game/[id]/page.tsx`: server page, `params: Promise<{id}>` (awaited per Next 16 docs), `getGameById` + `notFound()` on miss/wrong org, placeholder canvas copy.
